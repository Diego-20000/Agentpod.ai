## 1. Datos que podemos procesar
- nombre, correo electrónico y datos básicos de cuenta;
- información necesaria para autenticar mediante Google o GitHub;
- información de suscripción, pedido y estado de pago recibida de Polar;
- identificadores de pods, servidores, especificaciones y estados técnicos;
- direcciones IP, información de sesión y registros de seguridad;
- logs técnicos necesarios para operar, diagnosticar y proteger el servicio;
- contenido que el cliente almacene, ejecute o transmita dentro de su pod, en la medida necesaria para prestar el servicio, mantenerlo, investigar incidentes de seguridad o cumplir obligaciones legales.

AgentPod no almacena los números completos de las tarjetas de pago utilizados en Polar.

## 2. Para qué utilizamos los datos
- crear y administrar cuentas;
- provisionar y administrar pods;
- procesar suscripciones y relacionarlas con el servicio;
- proporcionar soporte;
- detectar y responder a fraude, abuso e incidentes de seguridad;
- mantener registros técnicos y operativos;
- cumplir obligaciones legales;
- mejorar la confiabilidad y seguridad del servicio.

No utilizamos el contenido de los pods de los clientes para entrenar modelos de inteligencia artificial propios.

## 3. Proveedores externos
AgentPod puede compartir o procesar datos mediante proveedores necesarios para prestar el servicio, incluyendo:
- **Polar**, para checkout, suscripciones, pagos y funciones de Merchant of Record;
- **Hetzner**, para infraestructura cloud donde se ejecutan los pods;
- **Google y GitHub**, cuando el cliente utiliza esos proveedores para autenticación.

Estos proveedores pueden procesar datos desde otras jurisdicciones. Las transferencias internacionales se realizarán conforme a la legislación aplicable y a los mecanismos contractuales o legales que correspondan. Argentina cuenta con cláusulas contractuales modelo para transferencias internacionales aprobadas por la AAIP.

## 4. Retención
Conservamos los datos durante el tiempo necesario para prestar el servicio, cumplir obligaciones legales, resolver disputas y mantener registros de seguridad razonables.
Cuando un pod es eliminado o archivado, AgentPod puede conservar un snapshot durante 7 días para recuperación (ver `docs/OPERATIONS.md` §3).
Transcurrido ese período, el snapshot puede eliminarse permanentemente.
Algunos registros administrativos, de facturación o seguridad pueden conservarse durante más tiempo cuando exista una obligación legal o una razón legítima para hacerlo.

## 5. Acceso técnico al pod
Para proporcionar soporte, seguridad, mantenimiento o responder a incidentes, AgentPod puede acceder a información técnica del entorno del cliente cuando sea razonablemente necesario.
No accederemos deliberadamente al contenido del cliente fuera de esas finalidades, salvo consentimiento del cliente, necesidad de seguridad o cumplimiento de una obligación legal.

## 7. Seguridad
Aplicamos medidas razonables para proteger la información, incluyendo controles de acceso, autenticación, cifrado en tránsito, gestión de credenciales y medidas técnicas contra abuso (ver `docs/OPERATIONS.md` §2).
Ningún sistema conectado a Internet puede garantizar seguridad absoluta.
